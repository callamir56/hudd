# vn-hud — Vehicle Radio (Q)

رادیوی ماشین با کلید **Q** باز/بسته می‌شود و رابط کاربری آن دقیقاً به شکل
پلیر موزیک مرجع ساخته شده است: پنل بزرگِ وسط صفحه با پس‌زمینه‌ی سبزآبی
نیمه‌شفاف، کاور تیره با آیکن نُت سفید، نوار پیشرفت (Seek)، و دکمه‌های
Shuffle · قبلی · Play/Pause بزرگ · بعدی · Repeat.

بقیه‌ی بخش‌های HUD (وضعیت، قطب‌نما، ماشین، چت و…) بدون تغییر باقی مانده‌اند.

## کنترل‌ها

| کنترل | عملکرد |
|---|---|
| `Q` / `ESC` | باز و بسته کردن رادیو (فقط صندلی راننده و سرنشین جلو — `Config.Radio.ControllerSeats`) |
| دکمه‌ی وسط (▶ / ❚❚) یا `Space` | پخش / توقف |
| ⏮ / ⏭ یا `←` / `→` | ترک قبلی / بعدی ایستگاه فعلی (به‌ترتیب لیست `tracks`؛ اگر کمتر از ۳ ثانیه از ترک گذشته باشد، ⏮ به ابتدای ترک برمی‌گردد) |
| 🔀 Shuffle | روشن: ترک بعدی/قبلی تصادفی انتخاب می‌شود |
| 🔁 Repeat | تکرار همان ترک (`audio.loop`) |
| نوار پیشرفت | Seek — فقط برای فایل‌های صوتی با مدت مشخص؛ برای استریم زنده غیرفعال و با برچسب `LIVE` نمایش داده می‌شود |
| چیپ‌های ایستگاه | انتخاب ایستگاه؛ کلیک دوباره روی ایستگاه در حال پخش آن را خاموش می‌کند |
| اسلایدر صدا / اسکرول ماوس روی پنل | حجم صدای کابین (بین همه‌ی سرنشینان سینک می‌شود) |

## افزودن موزیک به ایستگاه

در `config.lua`، بخش `Config.Radio.Stations`، آدرس مستقیم فایل‌های صوتی
(mp3/ogg یا استریم) را داخل `tracks` هر ایستگاه بگذارید:

```lua
{
    id = 'shadow',
    label = 'SHADOW',
    tracks = {
        'https://example.com/track1.mp3',
        'https://example.com/track2.mp3',
    }
},
```

ایستگاه‌هایی که `tracks` خالی داشته باشند در UI با برچسب `EMPTY` غیرفعال‌اند.

## فایل‌های درگیر این تغییر

- `html/index.html` — ساختار پلیر (کاور، seek، کنترل‌ها)
- `html/style.css` — استایل پنل (فقط بلاک `.radio-*`)
- `html/app.js` — منطق پلیر (پخش/توقف، seek، بعدی/قبلی، shuffle/repeat، صدا)
- `client/radio.lua` — کالبک‌های NUI جدید: `vnRadioNext` / `vnRadioPrev` / `vnRadioShuffle`
- `server/radio.lua` — پیمایش ترتیبی ترک‌ها با نگهداری `index` برای هر خودرو (`radioNext`/`radioPrev` + حالت shuffle)

نکته: Pause محلی است (فقط پخش همان کلاینت متوقف می‌شود) تا سینک رادیوی
خودرو برای بقیه‌ی سرنشینان به‌هم نریزد؛ عوض‌شدن ایستگاه یا ترک، پخش را
دوباره شروع می‌کند.

## آیکون اختصاصی هر مود چت

هر تگ/مود چت در کارت پیام، آیکون مخصوص خودش را دارد (تعریف‌شده در
`chatTagIcons` داخل `html/app.js`):

| تگ | آیکون | تگ | آیکون |
|---|---|---|---|
| `IC` / `RP` | حباب گفت‌وگو با خط‌های دیالوگ | `TWOTTER` | ‏X |
| `OOC` | کیبورد (بازیکن واقعی) | `PM` | پاکت نامه |
| `LOOC` | پین لوکیشن | `ADMIN` | سپر با تیک |
| `ME` | آدمک (اکشن) | `F` / `JOB` | کیف کاری |
| `DO` | ماسک تئاتر (صحنه) | `DEP` | بی‌سیم (واکی‌تاکی) |
| `WHISPER` | بلندگو با موج آرام | `ANNOUNCEMENT` / `ANN` | امواج پخش (برادکست) |
| `SHOUT` | مگافون | `BOT` | سر ربات |
| `TRY` | تاس چهارخال | `ID` | کارت شناسایی |
| `ROLL` | تاس پنج‌خال | `DENIED` / `FAILED` / `ERROR` | دایره‌ی خط‌خورده / ضربدر |
| `COIN` | سکه | `SUCCESS` | دایره با تیک |
| `ANTI-SPAM` / `SPAM` | کرنومتر | `WARNING` | مثلث هشدار |
| `SYSTEM` / `SERVER` / `INFO` | دایره‌ی اطلاعات | (بدون تگ) | حباب پیام پیش‌فرض |

اگر پیام تگ نداشته باشد ولی `type` یا `mode` داشته باشد، آیکون از روی
همان انتخاب می‌شود. برای افزودن تگ جدید کافی است یک ورودی به
`chatTagIcons` اضافه کنید؛ رنگ کارت از رنگ خود پیام می‌آید.
